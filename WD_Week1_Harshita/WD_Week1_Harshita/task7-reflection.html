Task 7: Reflection & Learning

What did I learn about HTML?

This week I learned that HTML gives structure to every web page. I understood the basic document structure, how to format text, and how to add links, images, lists and tables. I also learned how forms collect user data and how semantic tags give meaning to different parts of a page.

Which topic was the most challenging?

Forms were the most challenging. Choosing the correct input types, connecting labels to inputs with the "for" and "id" attributes, and grouping radio buttons with the same name took practice.

Which HTML concepts did I enjoy the most?

I enjoyed semantic HTML and building the mini project, because I could see all the separate concepts come together into one complete website.

How will HTML help me in web development?

HTML is the foundation of web development. CSS and JavaScript both work on top of HTML, so a strong understanding of structure will make styling and adding interactivity much easier in the coming weeks.
