Task 1: HTML Document Structure

This page shows the basic structure every HTML5 document follows.

Parts of this document

  • <!DOCTYPE html> - declares the document as HTML5.
  • <html> - the root element that wraps the whole page.
  • <head> - holds information about the page (not shown on screen).
  • <title> - the text shown on the browser tab.
  • <meta charset="UTF-8"> - supports all characters and symbols.
  • <meta name="viewport"> - makes the page mobile friendly.
  • <body> - holds everything visible on the page.
