1. CSS Syntax

A CSS rule has a selector and a declaration block. Each declaration is a property and a value.

selector {
    property: value;
}

h2 {
    color: #0f4c5c;
    font-size: 1.5rem;
}

2. Selectors

  • Universal selector (*) resets margin and padding for every element.
  • Element selector (h2, p) styles all headings and paragraphs.
  • Class selector (.card) styles every box on this page.
  • ID selector (#page-header) styles only the header at the top.

The yellow words in this page use the class .highlight.

This paragraph is styled with the ID selector #unique-text.
